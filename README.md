# orca-wrapped
Wrap up your ORCA card taps to review your transit travels. Head to [moshobo.github.io/orca-wrapped](https://moshobo.github.io/orca-wrapped/) to wrap up your ORCA card taps!

![wrapped-example](https://github.com/user-attachments/assets/0a5b16c2-0c54-42b9-b493-0262ea41cbce)

## Limitations
Unfortunately, if your ORCA card is managed/owned by your employer, you will not be able to get the necessary data from myorca.com

## FAQ
1. **What do you do with my data when I upload it?** Nothing. This code is all run within your browser and does not require sending it to any server or database. Check it out for yourself in the [script.js](https://github.com/moshobo/orca-wrapped/blob/main/script.js) file.
2. **Is this associated with the ORCA transit agency, or any other transit agencies in the Puget Sound?** No, this is a personal project and is not affiliated with any transit agencies.
